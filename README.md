# Mi currículum

Soy Francisco Puñal y actualmente estoy cursando 2º de Desarrollo de Aplicaciones Web (DAW).

He creado este repositorio para tener mi currículum y mi carta de presentación, pero también para practicar HTML, CSS y Git mientras preparo la búsqueda de prácticas y empleo.

El CV está hecho con HTML y CSS, sin frameworks. He intentado que tenga un diseño sencillo, que se pueda consultar desde el navegador y que también quede bien al guardarlo en PDF, en una sola página A4.

En el repositorio están el código fuente, el currículum en PDF, mi carta de presentación y algún certificado de formación.
